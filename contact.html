Questions & Answers

Frequently Asked Questions

Quickly find answers to common queries regarding Stackly systems.

How do the soil moisture sensors report data?

Our field telemetry units connect to a local LoRa gateway node installed on your farm. The gateway transmits readings to Stackly databases using cellular links, updating your dashboard metrics every 15 minutes.

Do I need an active internet connection to run the auto irrigation valve?

No. While the valves sync settings from the cloud when connected, they contain internal microcontrollers that execute pre-programmed scheduling rules locally even if connection is temporarily lost.

Can I add multiple user accounts for my farm workers?

Yes. Registered Farm operators can configure access permissions for crew members, allowing workers to update task lists and read weather metrics without accessing budget details.

Is there an onboarding fee for soil mapping set ups?

Standard registration includes basic set up checklists. Large scale field mappings involving drone flyovers feature custom quotes based on monitored acreage sizes.
